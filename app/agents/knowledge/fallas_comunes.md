# Base de conocimiento tecnica

Catalogo inicial para orientar diagnosticos. Las recomendaciones son provisionales:
confirmar modelo, compatibilidad y causa mediante inspeccion antes de cambiar piezas.
La disponibilidad y el precio se validan exclusivamente en el inventario.

## Sobrecalentamiento y apagado repentino
- Sintomas: ventilador ruidoso, carcasa muy caliente, rendimiento reducido o apagados bajo carga.
- Causas probables: polvo en ventilacion/disipador, pasta termica degradada o ventilador desgastado.
- Diagnostico sugerido: verificar temperaturas, flujo de aire, giro del ventilador y estado del disipador.
- Solucion: limpieza interna y renovacion de pasta termica; cambiar el ventilador solo si falla la prueba.
- Componentes posibles: pasta termica y ventilador interno exacto para marca y modelo.
- Compatibilidad: comprobar numero de parte, conector, dimensiones y voltaje del ventilador.

## Equipo no enciende
- Sintomas: no hay luces ni arranque, o el equipo se apaga inmediatamente al pulsar encendido.
- Causas probables: cargador defectuoso, bateria descargada/degradada, puerto de carga o circuito de alimentacion.
- Diagnostico sugerido: medir cargador y puerto, probar encendido con bateria desconectada cuando el modelo lo permita.
- Solucion: reemplazar cargador o bateria solo tras probarlos; reparar puerto o placa requiere diagnostico electrico.
- Componentes posibles: cargador compatible, bateria o conector DC-in especificos del modelo.
- Compatibilidad: verificar voltaje, amperaje, polaridad, forma del conector y numero de parte.

## Bateria no carga o dura poco
- Sintomas: porcentaje detenido, descarga rapida, apagado al desconectar el cargador o aviso de bateria degradada.
- Causas probables: desgaste de celdas, cargador insuficiente, conector flojo o circuito de carga.
- Diagnostico sugerido: revisar salud/ciclos de bateria, potencia del cargador y estabilidad del conector.
- Solucion: sustituir bateria solo si el reporte de salud y la prueba confirman degradacion.
- Componentes posibles: bateria interna o cargador con especificacion aprobada para el modelo.
- Compatibilidad: confirmar voltaje, capacidad, forma, conector y referencia del fabricante.

## Laptop lenta o almacenamiento lleno
- Sintomas: inicio lento, aplicaciones que tardan, pausas al abrir archivos o poco espacio disponible.
- Causas probables: disco degradado, almacenamiento lleno, poca memoria o software en segundo plano.
- Diagnostico sugerido: revisar salud SMART, espacio libre, uso de memoria y procesos antes de cotizar hardware.
- Solucion: mantenimiento de software; migrar a SSD o ampliar RAM solo si las pruebas lo justifican.
- Componentes posibles: SSD SATA/NVMe y modulo RAM compatible con la placa.
- Compatibilidad: comprobar interfaz, largo/formato, capacidad maxima, generacion y velocidad de RAM admitida.

## Pantalla azul, bloqueos o reinicios
- Sintomas: errores de sistema, congelamientos o reinicios repetidos durante el uso.
- Causas probables: controladores, archivos del sistema, memoria RAM defectuosa o almacenamiento con errores.
- Diagnostico sugerido: registrar codigo de error, revisar eventos, probar memoria y ejecutar diagnostico SMART.
- Solucion: corregir software/controladores; reemplazar RAM o almacenamiento unicamente si las pruebas fallan.
- Componentes posibles: modulo RAM o unidad SSD compatible, despues de aislar la falla.
- Compatibilidad: confirmar tipo de memoria, capacidad soportada e interfaz/formato del almacenamiento.

## Pantalla sin imagen o con artefactos
- Sintomas: equipo enciende pero no muestra imagen, parpadea, presenta lineas o cambia al mover la tapa.
- Causas probables: brillo/salida seleccionada, cable eDP, panel, memoria o circuito grafico.
- Diagnostico sugerido: probar monitor externo, linterna, bisagras y cable antes de condenar el panel.
- Solucion: reconectar/cambiar cable o reemplazar panel solo tras aislar la causa.
- Componentes posibles: cable de pantalla o panel LCD exacto para la variante del equipo.
- Compatibilidad: validar tamano, resolucion, conector, posicion de anclajes y referencia del panel.

## Wi-Fi intermitente o sin conexion
- Sintomas: redes ausentes, desconexiones, senal debil o Wi-Fi que deja de funcionar tras suspender.
- Causas probables: controlador, router, antenas desconectadas o tarjeta inalambrica defectuosa.
- Diagnostico sugerido: comparar otros dispositivos/redes, reinstalar controlador e inspeccionar antenas.
- Solucion: corregir configuracion/controlador; sustituir tarjeta solo despues de descartar red y antenas.
- Componentes posibles: tarjeta Wi-Fi y, si esta danada, antenas compatibles.
- Compatibilidad: comprobar interfaz, formato, soporte de BIOS y normativa/regional del equipo.
