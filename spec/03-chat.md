# 03 — Chat del cliente

Portal con acceso por usuario/contraseña configurados por el operador, sesión de duración limitada y cierre de sesión.
API de chat protegida, historial aislado por cliente y mensajes/respuestas visibles.
Orientación determinista en español y acceso a presupuesto de demostración por solicitud explícita.
Los mensajes no constituyen diagnóstico confirmado. Ante falta de datos, pedir equipo y síntomas.
Historial y sesiones en memoria (una instancia); se pierden al reiniciar. Integración con identidad corporativa y persistencia quedan fuera de esta entrega.
